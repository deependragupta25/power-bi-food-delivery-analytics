# 🍔 Food Delivery Analytics Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard developed to analyze food delivery transactions, food categories, customer membership types, payment methods, delivery status, and monthly performance.

The project was completed as part of my hands-on learning and practice in data analytics.

## 🎯 Business Objectives

- Analyze food quantity and transaction performance.
- Understand transactions across different food types and membership categories.
- Monitor delivery status, including delivered and cancelled orders.
- Compare payment methods.
- Explore monthly performance trends using interactive filters.

## 🛠️ Tools & Technologies

- **Microsoft Excel:** Source data
- **Power Query:** Data preparation and appending monthly datasets
- **Power BI:** Data modeling, DAX measures, and interactive visualizations

## 📊 Dashboard Highlights

- KPI cards for Total Quantity, Transactions, and Average Quantity
- Monthly quantity analysis
- Transaction breakdown by food type and membership type
- Delivery status analysis
- Payment method comparison
- Interactive slicers for exploring data
